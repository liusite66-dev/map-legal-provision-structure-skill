# map-legal-provision-structure-skill

Build an offline, traceable hierarchy and citation graph from user-provided mainland-China normative legal texts.

Install by copying this directory into a supported tool's Skills directory. In Codex, it is installed at `~/.codex/skills/map-legal-provision-structure-skill`.

The Skill uses local MarkItDown conversion for non-text formats and writes an HTML graph, XLSX audit table, and scoped Mermaid diagrams. It does not search for missing legal texts or make legal-effect conclusions.
